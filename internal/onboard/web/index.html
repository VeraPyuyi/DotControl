连接本机 Codex

自动查找已安装的官方 Codex，并在独立任务目录中运行。安装不需要配置 SSH 或服务器。

高级任务设置（可选）

后台呈现不改变 Windows Computer Use 的前台限制。桌面任务仍需解锁并等待你空闲。

连接状态、暂停与测试

先让源设备的 Dot 调用本设备的 devices，确认名称和随机校验值。启用后再观察一个已打开的无害窗口，确认源 Dot 实际显示了图片。

只有你在本机启用后才接收操作。修复不会自动解除暂停。任务完成与图片交付分别记录。

SSH 与实验助手（可选，不影响安装）

从这台电脑的 SSH 配置与 ssh-agent 连接服务器，使用本机 VPN。这里只保存连接引用；密码、私钥正文和口令不要填入任何字段或发送到聊天。

加密私钥需在本机通过正常 SSH 流程解锁。主机指纹须由你核实，向导不会自动信任新主机。

仅使用内置实验助手时需要这些配置。一般 SSH 任务可以之后在 Windows Codex 中处理。

授权此公钥

首次使用时，选择公钥并核对指纹。密码只在接下来打开的系统 SSH 窗口输入。

共享 Codex 会话（只读）
首次启用默认共享这台电脑的全部本地会话，包括以后新增的会话。可以改为仅共享选中的聊天；历史读取与终端任务独立启用，暂停和撤销仍会阻止读取。
