## Privacy and coordination

Configuration contains user-selected references, not password/key bodies.
Diagnostics and public evidence exclude endpoints, paths and private task content.
Only owned official threads are managed. Scope instructions do not replace the
official permission system. Cua and native input share one device lease; a cancelled
context requests interruption but does not prove it stopped. Unconfirmed native
execution leaves a durable block across restart.

SSH reached the user-selected service but existing batch authentication failed.
No experiment was started. The user must finish local SSH authentication and select
an allowed remote directory; no password was used or stored by the implementation.
