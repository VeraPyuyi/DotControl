# DotControl v0.2.0-alpha.6

会话共享现在明确提供“全部会话（默认）”和“仅白名单中的会话”。首次启用历史读取时，
默认允许全部本地 Codex 会话，包括未来新增的会话；已有设备继续显示实际保存的范围，
升级不会将原白名单恢复为全部共享。

## 共享范围

- 仅在选择白名单模式时显示搜索、分页和勾选区域。
- 两种模式统一通过“预览共享范围 → 确认并保存共享范围”生效。
- 切换选项、清空候选均只编辑草稿；明确保存空白名单表示禁止全部读取。
- 状态刷新和多标签页修改保留尚未保存的编辑；旧修订号或已更改草稿的预览失效。
- 历史读取仍须单独启用，暂停、撤销和损坏配置的处理保持不变。MCP 仍为 13 个工具。
- 同步更新安装助手和共享技能说明。

## 安装与升级

提供 Windows x64 EXE、Mac Apple Silicon / Intel DMG 和安装助手，附校验和及许可证。
保留原设备、隧道、系统凭据、端口、终端配置、共享策略和任务记录。安装器正常退出旧代理，
新版健康检查通过后清理已确认归属的旧程序；清理受阻时保留新版并报告待处理。

未配置发布者签名或公证，不关闭系统安全检查。本轮不修改用户 Mac；Mac 原生 runner 的
构建和隔离安装验证不代表用户 Mac 真机权限或云端连接验收。原生 Computer Use 继续关闭，
SSH／实验助手及审批转发维持下线。实际发布与升级证据见[支持矩阵](RELEASE_SUPPORT.md)。
