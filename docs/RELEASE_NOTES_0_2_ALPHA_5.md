# DotControl v0.2.0-alpha.5

本版将长向导改为四区控制台：概览、连接设置、Codex、会话共享。状态卡分别报告本地服务、
云端轮询、源 Dot 调用及本机 Codex。高级配置和帮助按需展开，宽屏侧边导航、窄屏顶部导航；
状态更新与表单、候选选择分开，继续使用已认证会话和多标签页。

## 功能下线

- 移除 SSH／实验助手与旧任务人工处理的页面、专用实现和审批回答入口。
- MCP 从 14 个改为 13 个，删除 codex_review；保留六个窗口工具、四个 Codex 任务工具及三个历史读取工具。
- 新请求包含已退役服务器或实验字段时拒绝，不忽略后执行其他工作。旧请求仍查原记录，旧任务可查询与取消。
- 旧 on-request 配置不自动转为 never；需要目标电脑明确配置。意外审批或输入要求会请求中断，未确认停止保留不确定保护。
- 原生 Computer Use 继续关闭。Windows Codex 仍可按用户要求自行使用 SSH，DotControl 不再注入实验命令。

## 更新

下载对应 Windows x64、Mac ARM 或 Intel 安装包，保留原设备。用户状态、隧道、系统凭据、
端口、终端绑定、暂停／撤销、共享策略及任务记录保留。新版检查通过后清理已确认归属的旧程序。
未配置发布者签名或公证，不更改系统安全检查。本轮不修改用户 Mac。

升级后在源端官方插件设置点击 Refresh tools，在新会话核对 13 个工具。本地就绪、
云端连接、源端实际结果分别确认。实际发布与验收结果见 [支持矩阵](RELEASE_SUPPORT.md)。
