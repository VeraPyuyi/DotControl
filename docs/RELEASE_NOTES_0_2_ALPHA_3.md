# DotControl v0.2.0-alpha.3

此预发布版更新 Windows x64、Mac Apple Silicon 和 Mac Intel 安装包及 Codex 安装助手。
它从 PR #1 分支构建；发布不表示 PR 已合并，alpha.2 文件保持不变。

## 本版变化

- Windows 仅终端委派独立启用，无需驱动、桌面权限或预先配置 SSH。使用目标电脑现有官方 Codex 登录和本机权限范围。
- 会话只读共享：首次本机启用默认全部共享，也可确认允许清单。历史读取和任务执行分别授权；远程无法修改共享范围。
- 向导登录支持 12 小时空闲有效期、24 小时硬期限和多标签页；迟到响应不覆盖新的登录或审批详情。
- 升级先校验文件，停止新任务并等待旧代理正常退出，再启动和检查新版。健康检查成功后才清理旧清单内的程序文件。
- 清理失败保持新版运行，显示待清理；修复继续清理。修改过的文件、用户文件、设备状态和系统凭据保留。
- 保留设备、隧道、暂停／撤销、终端权限绑定、共享清单修订号和动作历史。升级不会自动启用新权限。

## 下载与使用

- `DotControl-0.2.0-alpha.3-windows-amd64-setup.exe`
- `DotControl-0.2.0-alpha.3-macos-arm64.dmg`
- `DotControl-0.2.0-alpha.3-macos-amd64.dmg`
- `DotControl-onboarding-0.2.0-alpha.3.zip`

每个文件均配有 SHA-256。安装器包含固定依赖和第三方许可证，用户不需要开发工具。
已有设备请选择保留原设备。安装后在官方私有插件设置点击“刷新工具”，核对总计 14 个工具。
本机就绪、隧道在线、源 Dot 能调用新版工具是三个独立检查。

旧版本若没有安全升级退出接口，安装器会要求正常退出旧代理再重试；不会强制结束或删除锁。
Mac 本版交付安装包，用户真机升级、权限确认及新版跨电脑操作仍须单独验收。

## 边界

第一方安装包未配置发布者签名或公证。固定 CuaDriver 的上游签名在 Mac 构建和安装时独立检查，失败不重签。
官方 Computer Use 委派和远程审批继续关闭。Windows 终端任务、历史读取、图片交付、源端显示分别报告验证结果。
本次发布不增加 SSH、实验部署或桌面权限要求；旧 unknown 记录不改写，不重放任务。

最新检查见[支持矩阵](RELEASE_SUPPORT.md)。构建及包内校验不等于真实桌面操作通过。
